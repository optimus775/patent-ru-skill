# Примеры

Каталог содержит демонстрационные исходные материалы для проверки `patent-ru-skill`.

| Путь | Описание |
|---|---|
| `example_batch_job_scheduler/` | пример проекта о распределенном планировании пакетных задач и ресурсной осведомленности |

## Как использовать пример

1. Установите skill по инструкции из `INSTALL.md`.
2. Передайте агенту каталог:

```text
Используй patent-ru-skill.
Проанализируй examples/example_batch_job_scheduler/knowledge/
и подготовь материалы российской заявки на изобретение.
```

3. Агент должен просканировать Markdown, Office-файлы и код, затем подготовить результаты в `outputs/{case}/`.

Ожидаемые результаты полного запуска: список кандидатных решений, заметки по уровню техники, preview, итоговые `.md` и `.docx` с описанием, формулой, рефератом и фигурами.
