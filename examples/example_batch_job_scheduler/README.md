# Пример: распределенное планирование пакетных задач

Этот каталог содержит вымышленные исходные материалы для тренировки skill. В нем есть только `knowledge/`: архитектурное описание, Office-файлы и фрагменты кода.

Результаты работы агента не хранятся в примере. Их следует создавать в `outputs/{case}/`.

## Содержимое

| Путь | Описание |
|---|---|
| `knowledge/docs/` | архитектурные заметки, Word/PPT и изображения |
| `knowledge/pkg/scheduler/` | демонстрационные Go-файлы с фрагментами логики планировщика |
| `knowledge/meeting_notes_intake_example.md` | заметки вводного обсуждения |
