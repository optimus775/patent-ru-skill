# Платформа обработки данных: архитектура пакетного планировщика

> Это вымышленный учебный пример для `patent-ru-skill`; он не описывает реальный продукт.

## 1. Общая структура

- **Scheduler**: ведет глобальную очередь ожидающих задач, применяет настроенный приоритет и периодически отправляет задачи рабочим узлам.
- **Worker**: выполняет пакетные задачи и передает наблюдаемые метрики CPU, памяти и I/O.
- **Configuration service**: хранит статические правила: приоритеты задач, ресурсные пороги и affinity-метки.

## 2. Техническая проблема

- Узлы кластера неоднородны: часть узлов имеет более сильный CPU и локальный SSD, другие имеют высокую I/O-пропускную способность при среднем CPU.
- Большие задачи могут надолго занимать производительные узлы, а малые задачи ожидают на менее подходящих узлах.
- Статический приоритет и простые пороги нагрузки не учитывают совместно признаки требований задачи и многомерные профили узлов в реальном времени.

## 3. Целевой результат

- Снизить вероятность starvation для задач длинного хвоста.
- Улучшить соответствие задач неоднородным узлам.
- Сохранить стабильность планирования за счет минутных окон переупорядочивания вместо секундных колебаний очереди.

## 4. Модули

| Модуль | Роль |
|---|---|
| Агрегация ресурсных профилей | Собирает метрики узлов и сглаживает их в скользящем окне |
| Оценка соответствия | Вычисляет score по вектору требований задачи и профилю узла |
| Очередь с ограниченным переупорядочиванием | Переупорядочивает окно очереди только при выполнении порогов интервала и изменения score |
| Отправка | Передает задачи по порядку и обрабатывает retry-paths |
| Heartbeat-контракт | Выявляет вероятно недоступные узлы и поддерживает решения о миграции |

## 5. Связанные пути кода

- `pkg/scheduler/types.go`: структуры требований задач и профилей узлов.
- `pkg/scheduler/scorer.go`: расчет score соответствия.
- `pkg/scheduler/reorder.go`: триггер ограниченного переупорядочивания и логика окна очереди.
- `pkg/scheduler/heartbeat.go`: heartbeat и выявление вероятно недоступных узлов.
