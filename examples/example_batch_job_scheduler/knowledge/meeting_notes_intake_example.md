# Заметки вводного обсуждения (вымышленный пример)

**Дата**: 2026-03-15

**Тема**: задержка длинного хвоста и несоответствие ресурсов при пакетном планировании.

## Контекст

- Текущая платформа использует глобальную очередь приоритетов и неоднородные рабочие узлы.
- Эксплуатация сообщает, что малые задачи имеют завышенное время ожидания P99.
- Механизм миграции по порогу уже есть, но реагирует после отправки задачи; команде нужен лучший этап сопоставления до отправки.

## Решения и границы

- **Цель**: снизить starvation и несоответствие ресурсов без попытки секундной глобальной оптимальности.
- **Допустимая задержка**: решения планировщика могут обновляться в минутном окне.
- **Вне scope**: vendor-specific cloud API и привязка к конкретному storage-продукту.

## Ожидаемый дизайн-результат

- Дополнение архитектуры: ресурсные профили, score соответствия и ограниченное переупорядочивание очереди.
- Последующий патентный workflow: отдельный список кандидатных решений и заметки по уровню техники в каталоге результата.
