# Выделение решений и выбор объекта охраны (Step 3-4)

## Step 3: кандидатные решения

На основе сканирования выдели 3-5 кандидатных технических решений. Для каждого укажи:

- рабочее название;
- объект охраны: способ, устройство/система, носитель, применение или группа решений;
- ближайший известный подход, если он уже виден из материалов;
- техническую проблему;
- существенные признаки;
- технический результат;
- почему это не только организационный, математический или бизнес-эффект;
- какие сведения нужны для полного раскрытия.

## Step 4: выбор и объединение

Проверь, можно ли объединить несколько решений в одну заявку как группу, связанную единым изобретательским замыслом. По умолчанию выбери один основной комплект с наиболее сильной причинной связью "признаки -> технический результат".

## Критерии выбора

- признаки имеют технический характер и раскрыты в исходных материалах;
- есть понятная техническая проблема и объективный технический результат;
- решение можно осуществить специалистом без изобретательских догадок;
- формула может быть построена без чрезмерно узкой привязки к внутренней реализации;
- отличие от уровня техники можно сформулировать после Step 5.

## Выход

Подготовь краткую таблицу кандидатов и рекомендацию:

- основной объект заявки;
- нужно ли заявлять группу решений;
- какие признаки войдут в независимый пункт;
- какие признаки лучше оставить зависимыми;
- какие пробелы проверить до сборки описания и формулы.
